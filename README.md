# Alphonz Tony C — AI & Software Developer Portfolio

A responsive, static portfolio website built with HTML, CSS and vanilla JavaScript. No build step or framework installation is required.

## Run locally

1. Extract the ZIP file.
2. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish online

### GitHub Pages
1. Create a public repository, for example `alphonz-portfolio`.
2. Upload `index.html`, `styles.css`, `script.js` and this README to the repository root.
3. In GitHub, open **Settings → Pages**.
4. Under Build and deployment, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish the site. Your URL will be shown in the Pages settings.

### Vercel
1. Push the folder to a GitHub repository.
2. Import that repository into Vercel.
3. Select the default static project settings and deploy. No build command is needed; the output directory is the repository root.

## Personalise before publishing

- Confirm your preferred public name and education details.
- Add your verified LinkedIn profile URL in the contact section.
- Add live demos and repository links only when they are public and working.
- Add a resume PDF only after reviewing it for personal information.
- Check every project description and status for accuracy before sharing with recruiters.
